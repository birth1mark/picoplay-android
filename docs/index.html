// Features

Engineered for Handheld Perfection

Designed from the ground up for modern smartphones, gaming tablets, and dedicated Android retro handhelds.

🕹️

Pocket Touch Gamepad

Ergonomic fixed thumbstick with 8-way directional tracking and smart cardinal gating. Tactile circular [O] and [X] buttons placed for natural thumb resting.

🌐

In-App BBS Arcade Store

Browse featured community cartridges directly inside the app, download new games in a fraction of a second, or enter cartridge IDs via the built-in retro numeric keypad.

🎮

Gamepad Auto-Detection

Connect any Bluetooth or USB controller (PS4 DualShock, PS5, Xbox, 8BitDo, Retroid Pocket, Odin). The touch overlay automatically hides upon controller input for zero screen clutter.

📺

3 Smart Scaling Modes

Cycle with one tap between MAX (full 1080px edge-to-edge display), FIT (authentic framed handheld display with bezel), and 1:1 (pixel-perfect integer scaling).

💾

Instant Cartridge Importer

Tap [+CART] to open the native Android Storage Access Framework and load any .p8 or .p8.png cartridge from your Downloads, SD Card, or cloud storage.

⚡

Pure Native C++ Engine

Based on Fake-08 with low-latency OpenSL ES audio and accelerated SDL2 graphics. 100% compliant with Android 15 and 16KB memory page size alignment.

// Layout Guide

Touch & Controller Mapping

⭕

Primary Action [O]

Red button located at the lower right. Maps to PICO-8 Button 4 (Z / C). Triggers jump, confirm, or fire.

✖️

Secondary Action [X]

Blue button located above the O button. Maps to PICO-8 Button 5 (X / V). Triggers dash, action, or cancel.

🔘

Top Action Pills

[MENU] opens pause/settings. [+CART] invokes file picker. [SCALE] cycles between MAX, FIT, and 1:1.
