Privacy Policy for PicoPlay

Application: PicoPlay (com.birth1mark.picoplay) • Developer: birth1mark • Last Updated: October 2026

1. Zero Personal Data Collection

PicoPlay does not collect, store, transmit, or share any personal information, device identifiers, precise or approximate location data, usage analytics, or crash telemetry.

The application functions completely offline and contains no user account creation, login mechanisms, or authentication systems.

2. Local File Handling

When the user chooses to import a local cartridge file using the system file picker (Android Storage Access Framework), the file is read solely from the user's chosen location and copied to the application's isolated private internal storage directory on the device.

No user files, imported content, or saved game data are ever transmitted over any network or uploaded to external servers.

3. Device Permissions

  • android.permission.VIBRATE: Used exclusively to provide optional tactile haptic feedback when tapping on-screen virtual gamepad buttons.

PicoPlay requests zero network permissions and does not access contacts, camera, microphone, photos, or device storage outside the standard Android file picker.

4. Advertising and Third-Party SDKs

PicoPlay contains:

  • Zero advertisements or advertising tracking libraries.
  • Zero third-party analytics SDKs (no Firebase, no telemetry, no trackers).
  • Zero in-app purchases or financial payment integrations.

5. Children's Privacy

Because PicoPlay does not collect any personal data of any kind from any user, it fully complies with the Children's Online Privacy Protection Act (COPPA), GDPR, and Google Play Families policy requirements.

6. Security

All application operations and state files remain restricted to the sandboxed private application storage provided by the Android operating system.

7. Contact Information

If you have any questions or inquiries regarding this Privacy Policy, you may contact the developer via the official project repository issue tracker at:
